# Assets

Images for the plugin pages (Hangar, Spigot, GitHub). They are not part of the plugin jar.

- `icon.png`: the master icon, a 15x15 pixel-art sprite. Edit this one in a pixel-art editor (Aseprite, Piskel...).
- `icon-1024.png`: the icon exported for the plugin pages: `icon.png` scaled x64 with nearest neighbour (no smoothing),
  centered in a transparent 1024x1024 canvas. Export it again from `icon.png` after changing it.
- `banner.png`: the 1800x300 banner. There is no editable source: its bottle is the icon sprite (one more cork row,
  gray outline) scaled to 16.67 px per pixel over a blurred background.
